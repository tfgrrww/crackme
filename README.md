# SignalVM — Reverse Engineering Challenge

**Категория:** Reverse Engineering / Crackme  
**Сложность:** Hard / Insane  
**Платформа:** Linux x86_64 ELF  
**Формат флага:** `FLAG{...}`  

---

## 📜 Описание челленджа

Во время инцидента безопасности с одного из изолированных серверов был извлечен неизвестный исполняемый ELF-файл (`crackme`). Аналитики установили, что файл требует секретный ключ авторизации для разблокировки защищенного функционала.

Ваша задача как реверс-инженера — исследовать бинарный файл, преодолеть встроенные защитные механизмы и извлечь **цельный статичный секретный ключ** (флаг).

---

## 🎯 Правила и условия

1. **Секретный ключ цельный и статичный.** Ключ не формируется динамически по времени/сети и представляет собой единую фиксированную строку формата `FLAG{...}`.
2. Бинарный файл принимает ключ через стандартный поток ввода (`stdin`).
3. При вводе правильного ключа программа выводит:
   ```text
   [+] ACCESS GRANTED! Congratulations, reverse engineer!
   ```
   и завершается с кодом возврата `0`.
4. При вводе неверного ключа программа выводит сообщение об отказе и завершается с кодом `1`.

---

## 🚀 Быстрый старт

### Проверка целостности файла
Перед началом анализа убедитесь, что бинарник не был поврежден при клонировании:
```bash
sha256sum -c sha256sum.txt
```

### Запуск напрямую (Linux x86_64):
```bash
chmod +x ./crackme
./crackme
[?] Enter the secret key: FLAG{...}
```

### Запуск через Docker (для macOS / Windows / других дистрибутивов):
Если ваша основная система не Linux x86_64, вы можете запустить челлендж в изолированном контейнере:
```bash
docker compose up -d --build
nc localhost 1337
```

## 🛠️ Рекомендуемые инструменты для анализа

* Дизассемблеры и декомпиляторы: **Ghidra**, **IDA Pro**, **Binary Ninja**
* Динамический анализ: **GDB** (с плагинами GEF / pwndbg), **radare2** / **rizin**
* Трассировка и хуки: **Frida**, **Qiling Framework**, **Unicorn Engine**
* Системные утилиты: `readelf`, `objdump`, `strace`, `ltrace`

---

## ⚠️ Примечание

Все необходимые для решения данные содержатся исключительно внутри исполняемого файла `crackme`. Никаких внешних сервисов или сетевых подключений для поиска ключа не требуется.
